# 🎬 Módulo DigitalPass (Streaming & Herramientas IA) (mod-digitalpass)

> **Repositorio:** `mod-digitalpass`  
> **Rol:** Catálogo especializado para licencias de software, cuentas de streaming y créditos de Inteligencia Artificial.

---

## 📌 1. Descripción
Interfaz y controlador dedicado para comercializar cuentas de streaming (Netflix, Disney+, Max, etc.), suscripciones a herramientas IA (ChatGPT Plus, Claude, Midjourney) y activación de dongles/boxes de telefonía física vía Servidor 3 (`credits_3`).

---

## 🚀 2. Integración
- **URL Frontend:** `/digital-pass`
- **Fuente de Datos:** Endpoints de Servidor 3 (`/api/v1/s3/catalog` y `/api/v1/s3/order`).
